# GlitchMind 👾 — разговорный помощник в стиле hacker-HUD

Windows-программа, которая **слушает твой микрофон и звук из наушников** (каждый канал включается кнопкой),
расшифровывает речь на твоём компьютере, разбирает приёмы давления и манипуляции,
замечает признаки несостыковок в словах собеседника и **предлагает варианты ответа** —
на основе техник пяти книг:

| Автор | Книга | Что даёт программе |
|---|---|---|
| Мануэль Смит | Тренинг уверенности в себе | границы, «заезженная пластинка», затуманивание, уверенный отказ |
| Сьюзен Форвард | Эмоциональный шантаж | рычаги FOG (страх, долг, вина), четыре типа шантажистов, «вернуть ответственность» |
| Джордж Томпсон | Вербальное дзюдо | «не клюй на наживку», эмпатия как рычаг, пять шагов влияния |
| Крисс Восс | Никаких компромиссов | зеркала, метки эмоций, калиброванные вопросы, «Нет»-вопросы, модель Аккермана |
| Оливия Фокс Кобейн (в русском издании — Кабейн) | Харизма | присутствие, сила, теплота, подсказки по речи |

Всё работает **локально**: звук и текст не уходят в интернет (кроме разовой загрузки модели распознавания речи).

---

## Что важно знать заранее (честно)

* **«Наизусть» и тексты книг.** Тексты книг защищены авторским правом, поэтому в программу
  не вшиты их полные тексты. Вместо этого:
  1. внутри — **конспект приёмов своими словами** (39 приёмов из пяти книг: что это, как применять, пример);
  2. во вкладке **«БИБЛИОТЕКА»** ты можешь загрузить **свои легальные копии** книг
     (txt, md, fb2, epub, docx, pdf с текстом, html). Программа индексирует их на твоём компьютере и при каждом
     совете достаёт подходящие места из книги (поиск BM25) — это и есть «память» на книги.
* **«Обучить ИИ с нуля»** не имеет смысла: модель, понимающая русский язык, требует огромных данных и
  вычислений. Поэтому используется связка: **офлайн-движок правил** (работает всегда, мгновенно) +
  **локальная языковая модель** через [Ollama](https://ollama.com) (по желанию — для более «живых» советов).
* **Распознавание лжи — это не детектор лжи.** Надёжного признака лжи в голосе и словах не существует.
  Программа показывает *маркеры несостыковок*: клятвы и «честно говоря», размытую память, уход от ответа,
  противоречия с тем, что человек говорил раньше (числа, «да/нет»), отклонения темпа, паузы и высоты голоса
  от **его же** обычной нормы. Это повод задать уточняющий вопрос, а **не доказательство**.
  Нервничающий, но честный человек даст те же признаки.
* **Что проверено, а что нет.** Код писался и тестировался в Linux-песочнице: 92 автотеста (`python -m pytest`)
  и прогон интерфейса в Chromium (все вкладки, демо-разговор, без ошибок в консоли). **Не проверено на реальном Windows:**
  захват звука WASAPI (микрофон и loopback наушников), faster-whisper на настоящей речи, окно WebView2,
  сама сборка PyInstaller, а работа с Ollama проверена только на поддельном сервере.
  Сборка `.exe` в Linux невозможна — её нужно сделать на Windows (см. ниже).
  Если что-то не заработает — пришли `selftest.txt` и `%APPDATA%\GlitchMind\logs\app.log`, поправим.
* **Приватность и закон.** Запись и расшифровка чужого голоса без ведома собеседника во многих странах
  и ситуациях незаконна или требует согласия. При первом запуске программа просит подтвердить, что ты это понимаешь.
  Используй её, когда все участники разговора знают об этом, либо только для разбора своих реплик и собственных ситуаций.
* Советы — не психотерапия и не юридическая консультация. Если в речи появляются фразы о причинении себе вреда,
  программа напомнит про номер **112** — но она не заменяет живую помощь.

## Как получить GlitchMind.exe

### Вариант А — на своём Windows-компьютере

1. Установи **Python 3.12** с <https://www.python.org/downloads/> (галочка **Add python.exe to PATH**).
2. Распакуй проект и дважды щёлкни **`build.bat`**.
   Скрипт создаст окружение, поставит зависимости, прогонит тесты, соберёт exe и запустит самопроверку.
3. Готово: **`dist\GlitchMind\GlitchMind.exe`**. Копируй **всю папку** `dist\GlitchMind`, а не один файл.

Сборка занимает 5–15 минут и скачивает ≈ 300–500 МБ зависимостей.

### Вариант Б — через GitHub (без установки Python)

1. Создай приватный репозиторий на GitHub и загрузи туда содержимое проекта.
2. Вкладка **Actions → Build Windows exe → Run workflow**.
3. Когда сборка закончится, скачай архив **GlitchMind-windows** из раздела *Artifacts*, распакуй и запусти `GlitchMind.exe`.

### Запуск без сборки

`run_dev.bat` (или `python main.py`) запускает программу из исходников. Ключи:
`--browser` (открыть в обычном браузере), `--no-window` (только сервер, адрес печатается в консоль), `--selftest`.

## Первый запуск

1. Windows 10/11 должен иметь **WebView2** (на Windows 11 он уже есть; на Windows 10 при необходимости установи
   «Evergreen WebView2 Runtime» с сайта Microsoft). Без него программа откроется в обычном браузере.
2. Подтверди окно с согласием.
3. Нажми **▶ СЛУШАТЬ**. При первом включении скачается модель распознавания речи (`small`, ≈ 500 МБ)
   в `%APPDATA%\GlitchMind\models`. Дальше интернет для неё не нужен.
4. Под кнопкой два переключателя: **🎙 МИКРОФОН** — твой голос, **🎧 НАУШНИКИ** — звук, который идёт в наушники
   (снимается через WASAPI loopback устройства вывода — то есть **твоих наушников**; выбрать другое устройство
   можно в «Настройках»). Каждый канал включается и выключается отдельно, полоски рядом показывают уровень.
5. Кнопка **ДЕМО-РАЗГОВОР** проигрывает учебный диалог, чтобы посмотреть интерфейс без микрофона.

### Подключение «умной» модели (необязательно, но рекомендую)

1. Установи Ollama: <https://ollama.com/download>.
2. В командной строке: `ollama pull qwen2.5:7b` (для слабого ПК — `qwen2.5:3b`).
3. В программе: **НАСТРОЙКИ → ИИ-МОДЕЛЬ → Проверить связь**, затем выбери модель из списка.
   Подойдёт и любой сервер с OpenAI-совместимым API (LM Studio, llama.cpp server и т. п.): выбери тип *OpenAI-совместимый* и укажи адрес.

Без модели работает только офлайн-движок правил — он тоже даёт варианты ответов, но по шаблонам.

## Вкладки

* **LIVE** — живая расшифровка двух каналов, три шкалы (давление / манипуляция / несоответствия),
  найденные приёмы с названием книги, варианты ответа в стилях *Мягко / Твёрдо / Тактически / Границы*
  (клик — копировать), «чего не говорить», уточняющие вопросы, замечания к твоей собственной речи.
* **СИТУАЦИЯ** — опиши ситуацию или вставь переписку/диалог (`Он: …` / `Я: …`) — получишь разбор и ответы.
* **ЗНАНИЯ** — конспекты техник по каждой из пяти книг.
* **БИБЛИОТЕКА** — загрузка своих файлов книг, привязка к книге, проверка поиска.
* **НАСТРОЙКИ** — устройства, модель распознавания, чувствительность, ИИ, эффекты.

## Свой маскот

Нарисованный в коде «глитч-смайл» — оригинальный. Чтобы заменить его на свою картинку, положи файл
**`skin.png`** (или `.gif`, `.webp`, `.jpg`, `.svg`, до 8 МБ) в папку `%APPDATA%\GlitchMind` и перезапусти программу.
Логотип Nirvana и фирменные знаки Watch Dogs в проект не включены намеренно — это чужие торговые знаки и персонажи;
интерфейс лишь стилизован под «хакерский HUD» (неон, сканлайны, глитч).

## Где что лежит

| Что | Где |
|---|---|
| Настройки | `%APPDATA%\GlitchMind\config.json` |
| Книги (твои файлы) | `%APPDATA%\GlitchMind\library` |
| Индекс поиска | `%APPDATA%\GlitchMind\index` |
| Модели речи | `%APPDATA%\GlitchMind\models` |
| Логи | `%APPDATA%\GlitchMind\logs` |

Аудио не сохраняется на диск — только расшифровка в памяти текущего сеанса (кнопка «Очистить» стирает её).
Локальный сервер слушает только `127.0.0.1` и требует одноразовый токен сеанса.

## Структура проекта

```
main.py                 точка входа
glitchmind/
  app.py                окно (pywebview), запуск, --selftest
  server.py             локальный API (127.0.0.1, токен сеанса)
  controller.py         потоки: звук → ASR → анализ → советы
  audio/                захват (WASAPI loopback), VAD, ресэмплинг, ASR, признаки голоса
  analysis/             паттерны, маркеры несостыковок, ответы, движок
  knowledge/            конспекты книг, парсеры форматов, библиотека + поиск
  llm/                  клиент Ollama/OpenAI-совместимого API и промпты
  ui/                   интерфейс (HTML/CSS/JS)
tests/                  автотесты (pytest)
assets/                 иконка
glitchmind.spec         настройки PyInstaller
build.bat               сборка .exe одним кликом
.github/workflows/      сборка .exe в GitHub Actions
```
